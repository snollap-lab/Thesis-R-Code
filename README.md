# Thesis-R-Code
# PhD Thesis Analysis Code

This repository contains the R code used for the analyses presented in my PhD thesis, examining biopsychosocial predictors of adolescent substance use patterns using longitudinal data from the Adolescent Brain Cognitive Development (ABCD) Study.

## Overview

The thesis investigates factors associated with adolescent substance use across multiple levels of analysis, including:

* Psychopathology and substance-related outcome expectancies
* Substance use initiation and developmental trajectories
* Person-centred approaches to characterising substance use patterns
* Machine-learning approaches to identifying predictors of substance use
* Neurobiological correlates of substance use and decision-making

The analyses primarily use data from **ABCD Study Release 5.1** with the final analysis using data from **ABCD Study Release 6.0**.

## Requirements

Analyses were conducted in **R**. Packages required for individual analyses are specified within the relevant scripts.

Because the ABCD Study data are not publicly redistributed through this repository, users wishing to reproduce the analyses will need to obtain the appropriate ABCD data independently and have the necessary permissions to access them.

## Reproducibility

The repository is intended to document the analytical workflow underlying the thesis and facilitate transparency and reproducibility. Due to differences in data access, computing environments, package versions, and file paths, some modification may be required to run the scripts in a different environment.

## Data

The analyses use data from the **Adolescent Brain Cognitive Development (ABCD) Study**. Raw and processed participant-level data are not included in this repository.
